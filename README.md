The project  was to create a website to promote and market a community event 

This project was created as part of our WPR161 Web Programming group assignment at Belgium Campus.

The website was developed as a group, with each group member contributing to different parts of the project.

My main contribution to the project was the HTML development.

I worked on:

- Adding headings, paragraphs and sections
- Adding images and other HTML elements
- Creating links  between pages
- Organising the content of the website
